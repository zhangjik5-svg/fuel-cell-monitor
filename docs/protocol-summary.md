# SIO 通信协议摘要

本摘要用于说明上位机实现思路，不替代厂商原始协议文档，也不复制原始设备资料。

## 交互形式

- 设备命令提示符：`PFC>`；
- 上位机发送命令，设备返回文本响应；
- `LOG` 命令无参数，用于读取一次完整运行数据；
- 程序以 `PFC>` 作为响应结束标志，再将响应交给字段解析器；
- 协议 1.0.0 未定义 CRC 或校验和，程序执行提示符、帧结构和关键字段校验。

## 主要命令

| 命令 | 用途 | 上位机处理 |
|---|---|---|
| `LOG` | 读取测量值、运行信息和状态 | 实时曲线、Excel 记录、统计 |
| `WARNING` | 读取最近警告码 | 识别 `ErrorCode1/2` |
| `ERROR` | 读取最近错误记录 | 保存错误历史 |
| `ERRORSTAT` | 读取错误统计 | 保存错误统计响应 |
| `INFO` / `REV` | 读取设备或固件信息 | 保存原始响应 |
| `RTC` | 读取或设置 UTC 时间 | 保存原始响应 |
| `BAT` / `FM` / `CTRL` | 电池、燃料管理和系统控制 | 按需手动发送 |

## `LOG` 重点字段

| 字段 | 含义 |
|---|---|
| `POut` | 燃料电池输出功率 |
| `UBat` | 电池电压 |
| `UOut` / `IOut` | 系统输出电压 / 输出电流 |
| `TAmb` / `TStack` | 环境温度 / 电堆温度 |
| `THE` / `TMeOH` | 热交换器温度 / 甲醇温度 |
| `pDifComp` | 空气入口压差 |
| `FL` / `MeOHTotal` | 当前燃料桶余量 / 剩余燃料总量 |
| `SysOpTime` / `StackOpTime` | 系统上电时间 / 电堆运行时间 |
| `SystemStarts` / `StackStarts` | 系统启动次数 / 电堆启动次数 |
| `WOutCum` | 设备上报的累计输出量字段 |
| `SystemState` | 系统当前状态 |
| `DmfcPhase` | `0` 空闲、`1` 启动、`2` 充电 |
| `AutoCharge` | `1` 自动充电、`2` 手动充电 |
| `BattSoc` | 电池 SOC；设备未启用时返回 `-1` |
| `TStackMin` / `TStackMax` | 电堆最低 / 最高温度 |
| `ActiveErrors` | 当前错误估值码 |
| `SystemTime` | 设备当前时间 |

程序还会保存协议返回的其他字段，避免只保留界面显示值造成信息丢失。

## TFM6 接口边界

TFM6 燃料管理器的独立 RS485 接口为 `38400、8N1`，A/B 位于对应接口针脚。该参数属于燃料管理器接口，不应与燃料电池 SIO 实测配置混写。当前项目主要监控燃料电池 SIO 数据，未将 TFM6 RS485 当作实时曲线数据源。
