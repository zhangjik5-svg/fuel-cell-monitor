# 接线与测试说明

## 系统组成

1. 直接甲醇燃料电池：测试供电端；
2. 蓄电池组：连接在直流母线上，承担能量缓冲；
3. 电子负载：模拟耗电工况；
4. 功率计：测量测试回路的电压、电流和累计电量；
5. 电脑：通过串口运行监控上位机并保存数据。

## 功率关系

测试中应分别记录燃料电池输出、电子负载消耗和蓄电池充放电状态。由于蓄电池参与缓冲，瞬时功率不必满足燃料电池读数等于电子负载读数。分析时需要注明测量点、正负方向、负载设定、采样周期和实验起止时间。

## 现场验证

项目已使用真实设备完成线下调试。现有记录覆盖连续运行采集，包含完整响应统计、测量最小值/平均值/最大值、告警记录和累计输出电量。照片中的仪器读数与上位机读数应按各自测量位置和时间范围解释。
